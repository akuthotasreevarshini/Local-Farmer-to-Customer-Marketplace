# 🌱 FarmConnect – Local Farmer-to-Customer Marketplace

FarmConnect is a smart agricultural marketplace that connects local farmers directly with customers. It helps farmers sell their produce and enables customers to discover fresh products, compare prices, and find nearby farmers.

## ✨ Features

- 🛒 **Product Marketplace** – Browse agricultural products and view prices, quantities, and farmer details.
- 📸 **Product Image Upload** – Upload photos when adding or editing products.
- 👨‍🌾 **Farmer Dashboard** – Manage product listings and customer orders.
- 💰 **Price Comparison** – Compare products and prices from different farmers.
- 👥 **Group Buying** – Participate in group purchases and access community discounts.
- 🤖 **AI Assistant** – Get help with marketplace usage and agricultural questions.
- 🎤 **Voice Assistance** – Use voice input and spoken responses for easier access.
- 🌐 **Multilingual Support** – English, Telugu, and Hindi language options.
- 🗺️ **Interactive Map** – Discover nearby farmers and view approximate distances.
- 📱 **Responsive Design** – Use the application on desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js, TypeScript
- **Database:** MongoDB
- **Maps:** Leaflet and OpenStreetMap
- **Image Uploads:** Cloudinary integration
- **Voice Features:** Browser speech recognition and text-to-speech APIs

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- MongoDB
- Git

### Installation

1. Clone this repository.
2. Install the root, frontend, and backend dependencies using the package files provided in the project.
3. Configure the required environment variables using the example environment files.
4. Start MongoDB.
5. Start the backend and frontend using the scripts defined in their respective `package.json` files.

Refer to the project configuration and environment examples for exact setup commands and required variables.

## 🎯 Project Objective

FarmConnect aims to reduce barriers between farmers and customers, improve price transparency, and make agricultural commerce more accessible through multilingual and voice-enabled features.

## 🔮 Vision

To create an inclusive digital marketplace where farmers can reach more customers and buyers can make informed purchasing decisions.
